# Mad Catz X16
These were sold either as Mad Catz, or High Frequency (toys'r'us brand).

X16 version that gives you 16 memory cards in one, with page up/down buttons to switch. 

### Board
OEM pak utilizing a 4 MBit CMOS static ram chip, backed up by a battery to keep memory while
it is not inserted into a powered on system. There is some custom circuity to manage the LCD screen
and the additional address lines.

#### Hardware Specs

    Ram chip: MITSUBISHI M5M5408AFP 55LL
    4194304-BIT (524288-WORD BY 8-BIT) CMOS STATIC RAM
